# Contributing

Yukh Coordination welcomes protocol critique, conformance fixtures, interoperability experiments, and focused implementation proposals.

Before opening code:

1. link a governing issue;
2. state whether the change affects protocol, implementation, security, or documentation;
3. identify compatibility and privacy consequences;
4. add executable evidence for normative behavior;
5. keep provider-specific adapters outside the neutral core.

Use discussions or issues for questions. Never include credentials, private transcripts, or adopter-specific secrets.
