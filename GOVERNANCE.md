# Governance

Yukh Coordination is maintainer-led during foundation.

Issues define outcomes and acceptance criteria. Pull requests carry focused changes and link their governing issue. Material protocol, compatibility, security, persistence, identity, or topology changes require an ADR or RFC.

Accepted ADRs are immutable; later decisions supersede them explicitly. A green implementation does not by itself accept a public protocol change.

Project status must reflect evidence: `Done` requires merged work and satisfied acceptance criteria.
