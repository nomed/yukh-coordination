# Yukh Coordination Protocol

The sole normative protocol draft is [RFC-0001](docs/rfc/0001-protocol-v0.1.md).
This file is an informative entry point and intentionally contains no wire
examples or duplicate requirements.

Current status: **Draft 0.1; not an accepted compatibility commitment and not
production-ready.**

Machine-readable draft contracts are under [`schema/`](schema/). Conformance
fixtures and independent cross-runtime results are future evidence owned by
issue #4; their absence prevents acceptance of the draft.
